## Safe Git Operations
Allowed when scope is small:
- git status --short
- git diff -- <file>
- git add <file>
- git commit -m "type(scope): message"

Disallowed:
- git reset --hard
- git clean -fd
- git rebase -i
- git push --force
- broad multi-file refactors without approval
- schema/database migration unless explicitly requested

Commit style:

- docs(readme): ...
- fix(api): ...
- fix(ui): ...
- refactor(component): ...
- test(contract): ...
